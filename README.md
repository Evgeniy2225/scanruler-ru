# ScanRuler RU

Русский интерфейс для [ScanRuler от CNC Kitchen](https://github.com/CNCKitchen/scanruler). Версия русификатора **0.1.8** предназначена для **ScanRuler 0.11.3**.

**[Скачать русификатор для Windows](https://github.com/Evgeniy2225/scanruler-ru/releases/latest)**

## Быстрый старт

1. Установите [Node.js](https://nodejs.org/) 22 или новее с npm и [Git](https://git-scm.com/downloads/win).
2. В разделе **Assets** скачайте `scanruler-ru-<версия>.zip` и распакуйте в папку ScanRuler. Если программы ещё нет, выберите папку для установки.
3. Откройте **«Запустить ScanRuler.bat»**. При первой установке подтвердите загрузку программы клавишей **д** или **y**. После установки запустите BAT ещё раз.

**Чтобы обновиться**, сохраните проект и запустите **«Обновить ScanRuler.bat»**. Если у вас версия 0.1.5 или ранний архив 0.1.6, распакуйте новый ZIP вручную с заменой файлов. Перезапустите ScanRuler и нажмите **Ctrl+F5**.

Пользуетесь ScanRuler на сайте? Установите [браузерный скрипт](https://github.com/Evgeniy2225/scanruler-ru/releases/latest/download/scanruler-ru.user.js) через Tampermonkey или Violentmonkey.
