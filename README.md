# ScanRuler RU — русский интерфейс для ScanRuler

Неофициальный русификатор [ScanRuler by CNC Kitchen](https://github.com/CNCKitchen/scanruler) — приложения для измерения 3D-сканов, анализа отклонений и толщины стенок, 2D-измерений и обратного проектирования.

**[Скачать последнюю версию](https://github.com/Evgeniy2225/scanruler-ru/releases/latest)** · [Все релизы](https://github.com/Evgeniy2225/scanruler-ru/releases) · [История изменений](ru/CHANGELOG.md)

В разделе **Assets** последнего релиза выберите `scanruler-ru-<версия>.zip`. Это готовый комплект русификатора; сам ScanRuler устанавливается отдельно. Для браузерного расширения доступен отдельный [userscript](https://github.com/Evgeniy2225/scanruler-ru/releases/latest/download/scanruler-ru.user.js).

## Возможности и ограничения

- Более 4 000 переводов подписей, подсказок и сообщений интерфейса.
- **Alt+Shift+L** переключает русский и английский языки; выбор сохраняется в браузере.
- Русификатор подключается к готовой сборке и не изменяет исходники ScanRuler, данные проекта и форматы экспорта. Он переводит интерфейс, а не содержимое экспортируемых отчётов или ответы MCP-сервера агенту.
- Новые строки и некоторые редкие сообщения могут оставаться на английском. Совместимость с будущими версиями ScanRuler не гарантируется.

Версия 0.1.1 проверена на ScanRuler 0.9.4. Проект создан и дорабатывается с помощью ИИ; возможны ошибки перевода. Сообщайте о них в [Issues](https://github.com/Evgeniy2225/scanruler-ru/issues), указав версии приложения и русификатора, исходную надпись и контекст.

## Первая установка — Windows

Понадобятся [Node.js](https://nodejs.org/) 22 или новее, интернет для загрузки зависимостей и [Git](https://git-scm.com/downloads/win), если вы хотите обновлять ScanRuler через скрипт.

1. Скачайте исходники ScanRuler через **Code → Download ZIP** в [его репозитории](https://github.com/CNCKitchen/scanruler) и распакуйте либо выполните:

   ```sh
   git clone https://github.com/CNCKitchen/scanruler.git
   ```

2. Скачайте [последний релиз русификатора](https://github.com/Evgeniy2225/scanruler-ru/releases/latest) и распакуйте его ZIP в папку ScanRuler. Папка `ru` и три файла `.bat` должны лежать рядом с `package.json` **самого ScanRuler**.
3. Запустите **«Запустить ScanRuler.bat»**. При первом запуске он установит зависимости, соберёт приложение и откроет [локальную страницу](http://127.0.0.1:7317/). Это может занять несколько минут.
4. Не закрывайте окно консоли, пока работаете. Перед завершением сохраняйте проект средствами ScanRuler.

## Обновление русификатора

1. Сохраните открытый проект. Скачайте ZIP из [последнего релиза](https://github.com/Evgeniy2225/scanruler-ru/releases/latest).
2. Распакуйте его в ту же папку ScanRuler **с заменой файлов**. Если вы вручную меняли словари, заранее сохраните копию папки `ru`.
3. Запустите **«Запустить ScanRuler.bat»** ещё раз: он подключит новую версию скрипта к сборке. В браузере нажмите **Ctrl+F5**.

Если ScanRuler запускается другим способом, после замены файлов выполните из папки приложения:

```sh
node ru/apply.mjs dist
```

Пересобирать всё приложение для обновления готового русификатора не требуется. Если вместо релизного архива вы изменяли файлы в `ru/i18n` или `ru/src`, сначала выполните `node ru/build.mjs`.

**«Обновить ScanRuler.bat» обновляет само приложение ScanRuler**, пересобирает его и подключает имеющийся русификатор. Новые словари из этого репозитория он не скачивает. Скрипт обновления приложения рассчитан на установку через `git clone`; при установке ScanRuler из ZIP новую версию приложения нужно скачать отдельно и снова добавить русификатор.

## Вариант через Tampermonkey / Violentmonkey

Для перевода сайта без локальной установки ScanRuler:

1. Установите [Tampermonkey](https://www.tampermonkey.net/) или Violentmonkey.
2. Скачайте [последний `scanruler-ru.user.js`](https://github.com/Evgeniy2225/scanruler-ru/releases/latest/download/scanruler-ru.user.js) и установите его через менеджер userscript.
3. Откройте [scanruler.com](https://scanruler.com/).

Для обновления повторно установите файл из последнего релиза и перезагрузите страницу. Горячая клавиша **Alt+Shift+L** работает и в этом варианте.

## Подключение Claude — необязательно

Русский интерфейс работает без Claude. Для управления ScanRuler через ИИ-агента используется [scanruler-mcp](https://github.com/CNCKitchen/scanruler/blob/main/mcp/README.md).

1. Сначала запустите локальный ScanRuler, чтобы появилась папка `dist`.
2. Запустите **«Подключить Claude.bat»**. Скрипт добавляет сервер в Claude Desktop и, если доступен, в Claude Code. Перед изменением конфигурации Desktop создаётся резервная копия; экспорт направляется в `Документы\ScanRuler`.
3. Полностью закройте Claude Desktop и откройте снова. Попросите подключиться к ScanRuler и подтвердите подключение агента в приложении.

Скрипт подключения работает в тестовом режиме и проверен не на всех конфигурациях. Если он не сработал, используйте [инструкцию MCP-сервера](https://github.com/CNCKitchen/scanruler/blob/main/mcp/README.md); журнал находится в `ru/connect-claude.log`.

При подключении агента переданные ему данные, включая измерения и изображения детали, обрабатываются поставщиком модели. Внутренние имена объектов и ответы MCP остаются исходными: например, показанная в интерфейсе «Плоскость 1» может называться `Plane 1` в данных агента.

## Если перевод не появился

- Нажмите **Alt+Shift+L**: ранее мог быть выбран английский язык.
- Для локальной версии проверьте, что открыта страница `http://127.0.0.1:7317/`, затем снова запустите «Запустить ScanRuler.bat» и нажмите **Ctrl+F5**.
- После ручной пересборки ScanRuler повторите `node ru/apply.mjs dist`: пересборка удаляет подключённый скрипт из `dist`.
- Если английскими остались только отдельные надписи, сообщите о них в [Issues](https://github.com/Evgeniy2225/scanruler-ru/issues).

## Для разработчиков перевода

Словари лежат в `ru/i18n/*.json` и объединяются по имени файла; более поздние файлы переопределяют совпадающие ключи. Движок находится в `ru/src/runtime.js`, стили — в `ru/src/fonts.css`. Файлы `ru/scanruler-ru.js` и `ru/scanruler-ru.user.js` генерируются при сборке.

- `scanrulerRu.missing()` в консоли браузера показывает строки, для которых не найден перевод. В списке могут быть имена файлов и названия программ, которые переводить не нужно.
- `node ru/tools/new-strings.cjs` ищет кандидатов в исходниках ScanRuler и сохраняет их в `ru/i18n/_new-strings.txt`. Команду запускают в установленном ScanRuler с его зависимостями; результаты требуют ручной проверки.
- Шаблоны используют подстановки `{0}`, `{1}`: например, `"{0} points": "Точек: {0}"`. Сохраняйте номера подстановок; не добавляйте слишком общие шаблоны, способные захватывать произвольные предложения.

Из корня репозитория русификатора или папки ScanRuler:

```sh
node --test ru/tests/*.test.mjs
node ru/build.mjs
```

В установленном ScanRuler примените сборку командой `node ru/apply.mjs dist`. При публикации обновляйте версию в `ru/package.json` и включайте оба сгенерированных скрипта.
