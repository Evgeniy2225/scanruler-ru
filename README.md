# ScanRuler RU — русский интерфейс для ScanRuler

> ⚠️ **Сделано с помощью ИИ.** Весь проект — движок русификатора, перевод более 4 000 строк интерфейса,
> файлы запуска и скрипты подключения — создан с использованием ИИ (Claude, Anthropic) и проверен
> выборочно. Возможны неточности перевода и ошибки — сообщайте о них в Issues.
>
> 🧪 **«Подключить Claude.bat» работает в тестовом режиме.** Он проверен не на всех конфигурациях
> (разрабатывался под Claude Desktop из Microsoft Store на Windows 11). Перед изменением он делает резервную копию
> `claude_desktop_config.json`; если что-то пошло не так — пропишите сервер вручную (см. ниже).

Неофициальный русификатор для [ScanRuler by CNC Kitchen](https://github.com/CNCKitchen/scanruler) —
браузерного инструмента для измерения 3D-сканов: вписывание сфер, цилиндров и плоскостей,
карта отклонений от CAD, толщина стенок, 2D-измерения, обратное проектирование и инструменты сетки.

Русификатор **не меняет исходники ScanRuler**: это один скрипт, который подключается к собранному
приложению и на лету заменяет английские надписи на русские по словарю (более 4 000 строк). Поэтому он
переживает обновления ScanRuler, а новые строки просто остаются на английском, пока их не добавят в словарь.

- **Alt+Shift+L** — переключить язык RU ⇄ EN (запоминается в браузере).
- Отчёты, буфер обмена, экспорт STEP/DXF/SVG и ответы ИИ-агенту остаются на английском — так их
  читают CAD и агент.
- Для кириллицы используется шрифт Bahnschrift (есть в Windows 10/11), близкий к оригинальному Barlow.

## Установка (Windows)

Нужны [Node.js](https://nodejs.org/) 22 или новее и Git (для обновлений).

1. Скачайте ScanRuler: `git clone https://github.com/CNCKitchen/scanruler.git`
   (или ZIP с GitHub и распакуйте).
2. Скопируйте в папку ScanRuler из этого репозитория папку `ru` и три файла `.bat` (или распакуйте туда архив из раздела Releases).
3. Дважды щёлкните **«Запустить ScanRuler.bat»**. Первый раз он установит зависимости и
   соберёт приложение (несколько минут), затем откроет http://127.0.0.1:7317/ в браузере.
   Окно консоли не закрывайте, пока работаете.

| Файл | Что делает |
|---|---|
| `Запустить ScanRuler.bat` | Запуск русской версии на http://127.0.0.1:7317/ |
| `Обновить ScanRuler.bat` | `git pull`, пересборка, повторное подключение русификатора |
| `Подключить Claude.bat` | Прописывает ScanRuler в Claude Desktop и Claude Code (см. ниже) |

### Без установки — через Tampermonkey

Файл `ru/scanruler-ru.user.js` — userscript для [Tampermonkey](https://www.tampermonkey.net/) или
Violentmonkey. Установите его, и сайт https://scanruler.com/ откроется на русском.

## Подключение Claude (ИИ-агент)

ScanRuler умеет работать с ИИ-агентом через сервер [scanruler-mcp](https://github.com/CNCKitchen/scanruler/blob/main/mcp/README.md):
агент открывает файлы, вписывает элементы, ставит размеры и делает отчёты — у вас на глазах, с отменой каждого шага.

1. Запустите **«Подключить Claude.bat»** *(тестовый режим)*. Он делает резервную копию `claude_desktop_config.json`
   и добавляет туда сервер `scanruler`, настроенный на вашу локальную русскую сборку
   (`--serve …\dist`), а экспорт — в `Документы\ScanRuler`. Если установлен Claude Code, сервер
   добавляется и туда.
   Где Claude Desktop хранит настройки: новые версии из Microsoft Store —
   `%LOCALAPPDATA%\Claude-Data\claude_*\`, старые из Store —
   `%LOCALAPPDATA%\Packages\Claude_*\LocalCache\Roaming\Claude\`, обычный установщик — `%APPDATA%\Claude\`.
   Надёжнее всего открыть файл через Claude: **Настройки → Developer → Edit Config** и добавить вручную:

   ```json
   "mcpServers": {
     "scanruler": {
       "command": "cmd",
       "args": ["/c", "npx", "-y", "scanruler-mcp@latest",
                "--serve", "C:\\путь\\к\\ScanRuler\\dist",
                "--out", "C:\\путь\\к\\ScanRuler\\exports"]
     }
   }
   ```
2. **Полностью** закройте Claude Desktop (значок у часов → Quit) и откройте снова.
3. Напишите Claude: *«Подключись к ScanRuler»*. В первый раз ScanRuler предупредит, что данные,
   которые читает агент, уходят его модели, — нажмите «Подключить агента».
4. Дальше просите, называя файлы полным путём, например:
   *«Открой C:\Сканы\кронштейн.stl, впиши плоскость на основание и цилиндр в отверстие и измерь расстояние»*.

> **Важно:** с подключённым агентом ваши данные (измерения, изображения детали, имена файлов)
> уходят поставщику модели. Не подключайте агента при работе с деталями под NDA.

Сам агент видит интерфейс на английском (имена элементов вроде `Plane 1`), поэтому называть
элементы ему лучше так, как они называются в английской версии, — или просто описывать словами.

## Как устроено

```
ru/
  src/runtime.js     движок: MutationObserver, точные совпадения и шаблоны с {0}
  src/fonts.css      кириллица в шрифтах интерфейса, перенос длинных подписей
  i18n/*.json        словарь «английский → русский» (файлы сливаются по алфавиту)
  build.mjs          собирает scanruler-ru.js и scanruler-ru.user.js
  apply.mjs          копирует scanruler-ru.js в dist/ и подключает его в index.html
  connect-claude.ps1 настройка Claude Desktop / Claude Code (тестовый режим)
  claude-config.mjs  аккуратно добавляет сервер в claude_desktop_config.json
  tools/new-strings.cjs  ищет в исходниках строки, которых ещё нет в словаре
```

Строки с подстановками записываются шаблонами: `"{0} triangles": "{0} треугольников"`.
Если строка-счётчик переведена как `"Элементов: {0}"`, подстановка принимает только число.

### Пополнение словаря

- В браузере: F12 → Console → `scanrulerRu.missing()` — английские строки, встреченные на экране.
- По исходникам: `node ru/tools/new-strings.cjs` → `ru/i18n/_new-strings.txt`.

Добавьте переводы в `ru/i18n/*.json`, выполните `node ru/build.mjs` и `node ru/apply.mjs dist`.

## Лицензия

ScanRuler распространяется под AGPL-3.0; словарь — перевод строк интерфейса ScanRuler, поэтому
этот русификатор тоже распространяется под **AGPL-3.0-only**. Проект не связан с CNC Kitchen.
Название ScanRuler и логотип принадлежат их владельцу.
