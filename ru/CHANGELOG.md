# История изменений ScanRuler RU

## 0.1.4 — 2026-11-09

- Проверена совместимость со ScanRuler 0.10.2. Добавлен перевод отказа сохранения файла с недопустимым именем и общего сообщения о повреждённом проекте. Имена файлов и диагностические пути сохраняются.
- В словаре 4476 строк. Поиск непереведённых строк теперь включает обработку файлов проектов.
- Исправления подключения Claude из репозитория включены в архив: отдельный адрес интерфейса, проверки окружения, резервное копирование настроек, отсутствие удаления существующего подключения Claude Code.
- Проверки: 26 автоматических тестов и 62 состояния интерфейса на тестовом скане в браузере.
- Дополнительный BAT подключения ChatGPT остаётся отдельным файлом в репозитории, чтобы архив устанавливался обновлятором предыдущих версий.

### Ранее добавлено в репозиторий после 0.1.3

- Добавлен отдельный BAT подключения настольного ChatGPT/Codex. В релиз 0.1.3 не включён.
- Исправлено подключение Claude: используется адрес интерфейса на порту 7318 и прямой запуск Node.js; проверяются зависимости и готовность сборки. Ошибки возвращают ненулевой код, существующий сервер Claude Code не удаляется. Настройки Claude Desktop сохраняются с резервной копией и проверкой структуры JSON.
- Добавлены проверки записи настроек ChatGPT и Claude. Конфигурации реальных аккаунтов тестами не изменяются.

## 0.1.3 — 2026-11-09

- Проверена совместимость со ScanRuler 0.10.1. Добавлено 417 переводов, исправлено 4 существующих; всего 4474 строк в словаре.
- Переведены масштабирование скана, новые способы построения точек, прямых и плоскостей, зеркальное отражение, уплотнение сетки и построение замкнутой оболочки.
- Уточнены пояснения к допускам формы: минимальная зона и размах отклонений относительно наилучшего приближения различаются.
- Переведены новые статусы обработки, подписи единиц, сообщения экспорта и подсказки обратного проектирования.
- Исправлен регистр самостоятельных сообщений, в том числе «Эталон не загружен». В панели масштаба подпись «From» переведена как «Способ задания» без изменения её перевода в других местах.
- Инструмент поиска строк теперь учитывает длинные подсказки и статусы в верхнем регистре.
- Проверки: 19 автоматических тестов и обход 62 состояний интерфейса в отдельном браузере на тестовом скане.

## 0.1.2 — 2026-11-07

- При запуске через «Запустить ScanRuler.bat» проверяются последние релизы ScanRuler и русификатора.
- Консоль показывает установленную версию, наличие обновления и ссылку на скачивание.
- Проверка использует страницы релизов без API-токена, выполняет два запроса параллельно и ограничивает ожидание 8 секундами. Ошибки сети не прерывают запуск.
- При наличии обновления консоль предлагает установить его: «д»/«y» — подтвердить, Enter — пропустить. Прежние файлы сохраняются в `.scanruler-backups`; ошибки замены откатываются. ScanRuler собирается во временной папке до замены рабочей сборки.
- Исправлен запуск при занятом порте MCP: интерфейс обслуживается отдельно на порту 7318 (или следующем свободном), браузер открывается после готовности.
- «Обновить ScanRuler.bat» использует ту же проверку и предложение установки обоих компонентов.
- Исправлено открытие браузера без скрытия консоли; повторный запуск показывает пояснение и ждёт нажатия клавиши.
- Дополнены файлы существующего релиза 0.1.2 без создания новой версии.

## 0.1.1 — 2026-11-06

- Добавлены 205 переводов: подсказки измерений и геометрических допусков, сообщения об обработке сетки, резьбе, импорте STL, описания палитр и режимов отображения.
- Исправлены 96 существующих переводов; уточнены названия команд, поверхностных тел, метода наименьших квадратов и подсчёта элементов.
- Удалён шаблон, произвольно удалявший английский артикль. Общие шаблоны с предлогами больше не создают смешанные русско-английские предложения из неизвестного текста.
- Включены предыдущие исправления счётчиков, коротких шаблонов, кэша и переключения языка.
- Поиск недостающих строк охватывает модули, которые передают сообщения в интерфейс из вычислительного ядра.
- Добавлены семь автоматических проверок движка и словаря. Словарь содержит 4057 уникальных строк.

Проверено на локальной сборке ScanRuler 0.9.4: шесть рабочих областей, настройки, импорт тестового STL, создание точки, десять типов размеров и восемь типов допусков. В этих сценариях ошибок JavaScript нет. Названия программ, форматов и палитр сохранены. Редкие сообщения ядра и новые строки будущих версий могут оставаться на английском.

Терминология сверена с контекстом исходников и справочными материалами:
- [Autodesk: построение по траектории (Sweep)](https://help.autodesk.com/cloudhelp/2022/RUS/AutoCAD-Core/files/GUID-89EE26BD-D032-430C-AF3C-DF2BAD657391.htm).
- [NPL: Gaussian (least-squares) best fit](https://eprintspublications.npl.co.uk/7148/).

Проверка: `node --test ru/tests/*.test.mjs`.
Сборка: `node ru/build.mjs`, затем `node ru/apply.mjs dist`.
